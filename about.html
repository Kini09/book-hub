About Book Hub

Book Hub is a mini library website built for a Web Programming subject. Visitors can browse a small catalogue, filter by category, and download a sample PDF.

Before any download starts, a feedback form is required. That data is stored in a MySQL table using PHP prepared statements, which helps prevent SQL injection.

  • Frontend: HTML5, CSS3, vanilla JavaScript
  • Backend: PHP
  • Database: MySQL
